OpenFit build steps (run inside this folder)
1. npm i @capacitor/core @capacitor/cli @capacitor/android
2. npx cap init OpenFit com.openfit.app --web-dir=www
3. npx cap add android
4. npx cap sync
5. npx cap open android   (Android Studio: Build > Build Bundle(s)/APK(s) > Build APK(s))
